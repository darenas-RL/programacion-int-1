Cómo usar la propiedad de posición en CSS para alinear elementos

CSS Position y propiedades auxiliares.

Así que hay 5 valores principales de la Propiedad Position:

    position:
  • static
  • relative
  • absolute
  • fixed
  • sticky
y propiedades adicionales para establecer las coordenadas de un elemento:
  • top
  • right
  • bottom
  • left
  • z-index

z-index

Nosotros tenemos altura y anchura (x, y) son 2 dimensiones.
Z es la 3.ª dimensión. Un elemento en la página web aparece
delante de otros elementos como su z-index aumenta el valor.

1. Static

Position: static es el valor por defecto. Ya sea que lo declaremos
o no, los elementos se colocan en un orden normal en la página web.

2. Relative

Position: relative nos permite mover un elemento de su posición
original. Podemos usar top, right, bottom y left para moverlo.
El espacio que ocupaba el elemento en su posición original permanece.

3. Absolute

Position: absolute nos permite colocar un elemento en una posición
específica dentro de su contenedor más cercano que tenga
position: relative. Si no hay un contenedor con position: relative,
el elemento se posicionará automáticamente en el punto de inicio (top-left esquina) de su elemento padre.

Ahora parece que la caja azul ha desaparecido, pero no es así.
El cuadro azul se comporta como si se quitara el cuadro naranja,
por lo que sube al lugar del cuadro naranja.

4. Fixed

Position: fixed nos permite colocar un elemento en una posición
específica en la ventana del navegador. El elemento permanece en esa
posición incluso si el usuario desplaza la página.

5. Sticky

Position: sticky es una combinación de relative y fixed.
El elemento se comporta como relative hasta que alcanza un
umbral definido por top, right, bottom o left, momento en el cual
se comporta como fixed.
